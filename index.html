Why I made this

As awesome as Font Awesome (heh) and other modern icon libraries are, I miss the colorful little image icons that made older websites feel so full of personality. The tiny folders, hearts, and buttons deserve a place on today's web, too.

I made this archive to collect some of those classic icon sets and make them easier to browse and reuse with simple, modernized HTML and CSS. Each collection has a searchable gallery, copyable <span> classes, and spritesheet-based stylesheets. No Javascript or dependencies required.

Note: “Free” depends on each artist's actual license. This archive does not replace the creators' copyright or grant permissions their licenses do not provide.

A History of web icons

Before scalable icon fonts and modern SVG libraries, websites used tiny GIF and PNG images. Forum posts, blogs, and websites were full of colorful 16x16 and 32x32 graphics. Artists and designers released memorable collections including but not limited to: Mark James's Silk, Joseph North's Sweetie, Yusuke Kamiyamane's Diagona etc. Their visual language is closely tied to the desktop-software and early social-web era.

This project aims to archive and keep the original pixel art intact while presenting it through CSS sprites. One image holds all of the icons, and each CSS class reveals the right icon, similar to how spritesheets work in videogames.

How to use these icons

Choose a collection above. Its homepage lists the available stylesheets and exact icon class names. Each collection page offers collection, stylesheet-only, and spritesheet-only download links. For custom or bulk downloads, use the GitHub repository.

Import via CDN (jsDelivr)

1. Add the collection's stylesheet from jsDelivr to the head of your document. Each gallery page above contains stylesheet links. 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/cjlaserna/retro-icon-archive/famfamfam/silk.css">

2. Click an icon in the gallery to copy its HTML, then paste it wherever you'd like the icon to appear. 

<span class="YOUR_ICON_CLASS"></span>

Import via Node Package Manager (NPM)

1. Install the Retro Icons Archive package:

npm install @claserna/retro-icons-archive

2. Import which collections you want into your entry file. Each gallery page above contains import snippets. 

import "@claserna/retro-icons-archive/famfamfam/flags.css";

3. Click an icon in the gallery to copy its HTML, then paste it wherever you'd like the icon to appear. 

<span class="YOUR_ICON_CLASS"></span>

Notes

  • Icon sizing: Icons use fixed pixel dimensions (e.g., 16x16 or 32x32). Changing font-size will not resize them.
  • Enlarging icons: Use zoom: 2 to enlarge icons and their backgrounds together, or transform: scale() for visual scaling.
  • Padding: Avoid applying padding directly to icon elements. Add padding to their parent containers instead.
  • Borders: Avoid borders directly on icons, since they can change the element's rendered size and appearance.
  • Pixel rendering: image-rendering: pixelated is the default. If overridden, reset it to pixelated, especially when enlarging icons, for crisp, blocky pixels.
  • Background size: Do not override background-size or use background-size: cover on sprite icons; it can break sprite coordinates.
  • Background position: Do not override background-position. Each icon depends on its specific coordinates.
  • CSS conflicts: Global styles targeting span, i, or other elements can affect icon rendering.
  • Alignment: Icons render as inline-block elements. Use vertical-align or flexbox for alignment.
  • Accessibility: Decorative icons should use aria-hidden="true". Meaningful icons need accessible labels.
  • Asset paths: Keep PNG spritesheets in their expected locations relative to the imported CSS.
  • Transparency: Icons may contain transparent pixels. Their appearance depends on the background underneath.
  • Browser scaling: Browser zoom and non-integer scaling can make pixel art appear blurry.
