# FatCow 16x16 Icon Directory

Browse the [FatCow 16x16 collection on GitHub](https://github.com/cjlaserna/retro-icon-archive/tree/main/fatcow-16).

The collection page provides stylesheet and spritesheet downloads. To use the latest stylesheet from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/cjlaserna/retro-icon-archive/fatcow-16/icons.css">
<span class="fatcow_16_32_bit"></span>
```
