# Manentia Icon Directory

Browse the [Manentia collection on GitHub](https://github.com/cjlaserna/retro-icon-archive/tree/main/manentia).

Includes 245 icons in 6 collections. Collection pages provide current-collection download links. To use the latest stylesheet from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/cjlaserna/retro-icon-archive/manentia/alerts-and-color-codes.css">
```

Use the exact icon class from the gallery, for example `<span class="manentia_alerts_and_color_codes_alert_high"></span>`.
