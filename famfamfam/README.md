# FamFamFam Icon Directory

Browse the [FamFamFam collection on GitHub](https://github.com/cjlaserna/retro-icon-archive/tree/main/famfamfam).

1,391 icons in three independent collections: Silk (1000), Mini (144), Flags (247).

The collection page provides downloads for its CSS files and spritesheets. To use the latest Silk stylesheet from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/cjlaserna/retro-icon-archive/famfamfam/silk.css">
<span class="silk-lock"></span>
```
