# Drunkey Love Icon Directory

Browse the [Drunkey Love collection on GitHub](https://github.com/cjlaserna/retro-icon-archive/tree/main/drunkey-love).

Includes 142 icons. The collection page provides downloads for its stylesheet and spritesheet. To use the latest stylesheet from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/cjlaserna/retro-icon-archive/drunkey-love/icons.css">
```

Use the exact icon class from the gallery, for example `<span class="drunkey_love_icons_add"></span>`.
