# Diagona Icon Directory

Browse the [Diagona collection on GitHub](https://github.com/cjlaserna/retro-icon-archive/tree/main/diagona).

Includes 400 icons in 2 collections. Collection pages provide current-collection download links. To use the latest stylesheet from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/cjlaserna/retro-icon-archive/diagona/10.css">
```

Use the exact icon class from the gallery, for example `<span class="diagona_10_001"></span>`.
