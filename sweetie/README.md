# Sweetie Icon Directory

Browse the [Sweetie collection on GitHub](https://github.com/cjlaserna/retro-icon-archive/tree/main/sweetie).

Includes 219 icons in 2 collections. Collection pages provide current-collection download links. To use the latest stylesheet from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/cjlaserna/retro-icon-archive/sweetie/basepack.css">
```

Use the exact icon class from the gallery, for example `<span class="sweetie_basepack_16_arrow_down"></span>`.
