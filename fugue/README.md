# Fugue Icon Directory

Browse the [Fugue collection on GitHub](https://github.com/cjlaserna/retro-icon-archive/tree/main/fugue).

Includes 7,814 icons in 6 collections. Collection pages provide current-collection download links. To use the latest stylesheet from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/cjlaserna/retro-icon-archive/fugue/bonus-icons-24.css">
```

Use the exact icon class from the gallery, for example `<span class="fugue_bonus_icons_24_address_book"></span>`.
